# **App Name**: Synapse Serenity

## Core Features:

- Tone Generator: Generates pure tones with adjustable frequency and amplitude.
- Waveform Selection: Allows users to select from sine, square, sawtooth, and triangle waveforms.
- Bilateral Control: Enables linked or separate adjustment of frequencies and volumes for each ear.
- Data Logging: Saves user-defined sound profiles with frequency, amplitude, and waveform data to Firestore.
- Profile Recall: Allows users to load previously saved sound profiles from Firestore.
- Personalized Sound Recommendation: Suggests settings by prompting the user with questions about their hearing and experiences using an LLM tool

## Style Guidelines:

- Primary color: Deep indigo (#4F46E5) for a calming and focused atmosphere.
- Background color: Dark navy (#0E1525) provides a comfortable viewing experience and visual contrast.
- Accent color: Vibrant cyan (#06BCC1) for interactive elements and highlights, ensuring important controls stand out.
- Body and headline font: 'Inter' sans-serif for clear readability and a modern feel.
- Use minimalist line icons from Lucide React, maintaining a clean and technical aesthetic.
- Maintain a structured layout with clear separation of controls, using rounded elements for a friendly interface.
- Subtle transitions and animations to indicate state changes and user feedback without causing distraction.
